## 中文

一个面向小说写作的 Obsidian 插件：在文件树里显示字数，统计每天写了多少，提供写作面板和主页，并支持像 Word 一样在页边写批注。

所有功能只作用于你设定的**写作文件夹**，库里的其他笔记不受影响。

### 功能

**字数统计**

- 中文按字计数，英文按单词计数，连续的数字或字母数字组合算一个；标点、空格和 Markdown 语法不计入。
- 文件树里每个文档后面显示字数，文件夹显示其中所有文档的合计，文件夹的数字用另一种颜色区分。
- 可以设置忽略的文件和文件夹（比如大纲），它们不计入任何统计。

**每日统计**

- **今日净增**：今天文档实际多了多少字。删掉 100 字再写 100 字，净增为 0；粘贴进来的内容也算。
- **今日输入**：今天在键盘上打了多少字。删除、粘贴、撤销都不算。
- **写作时长**：在写作文件夹的文档里持续输入时计时，停下 30 秒后暂停。
- 修改忽略列表、更换写作文件夹、把文件移进写作文件夹时，这些文档以当前字数为起点，不会被算成今天写的。
- 记录从哪一天开始统计，并显示"第 N 天"。

**写作面板（右侧边栏）与主页文档**

- 右侧面板：数字卡片、最近写作、近 30 日柱状图、月历、年度热力图。
- 主页文档（默认放在写作文件夹里）：数字卡片、最近写作、近 7 日柱状图、月历、年度热力图。主页名称可以在设置里修改。
- 月历从周一开始，可以翻页，也可以点击月份打开年月选择框，回看从起始日期以来的任意月份。
- 鼠标悬停在柱状图、月历或热力图的格子上，会显示当天的字数。
- 点击"最近写作"里的文档：如果它已经在某个标签页打开，直接跳过去，不会重复打开。
- 主页在文件树里置顶显示，不能被拖动；被移出写作文件夹时会自动移回原处。

**编辑记录**

- 可以手动修改任意一天的净增、输入和时长，也可以修改起始日期。
- 支持粘贴 CSV（`日期,净增,输入,分钟`）或 JSON 批量导入，也可以把全部记录复制为 JSON。

**批注**

- 在写作文件夹的文档里选中一段文字，右键选择 **添加批注**，或使用命令添加。
- 批注卡片显示在编辑器右侧页边，和被批注的文字对齐。正文会自动往左让出位置，窗口太窄时才会重叠。
- 被批注的文字平时只显示下划线，选中批注时才高亮。
- 不进入编辑也可以选中、复制批注里的文字；点击铅笔按钮才能修改。
- 可以通过标题栏按钮、命令或设置随时显示或隐藏全部批注。
- 批注存放在插件数据里，**不会往正文插入任何标记**，也不影响字数统计。文档改名、移动后批注会跟着走。
- 如果被批注的文字被整段删除，批注会保留，并标记为"原文已找不到"。

**其他**

- 状态栏显示今日净增，点击打开写作面板。
- 左侧 Ribbon 按钮打开写作面板。
- 界面支持中文和英文，默认跟随 Obsidian 的语言设置。

### 命令

### 安装

插件尚未上架社区插件市场，需要手动安装：

1. 克隆本仓库，安装依赖并构建：
   ```bash
   npm install
   npm run build
   ```
2. 把生成的 `main.js`，以及 `manifest.json`、`styles.css` 复制到 `<你的库>/.obsidian/plugins/ob-novel-dashboard/`。
3. 重启 Obsidian，在 **设置 → 第三方插件** 中启用 **Novel Dashboard**。

需要 Obsidian 1.8.7 或更高版本。

### 数据与隐私

- 插件完全在本地运行，不发起任何网络请求。
- 字数、每日记录和批注都保存在 `.obsidian/plugins/ob-novel-dashboard/data.json`。
- 插件只会在写作文件夹里创建主页文档，以及在你更换写作文件夹时新建该文件夹；不会修改你的正文。

### 已知限制

- 批注只在编辑模式（实时预览或源码模式）中显示，阅读模式下看不到。
- 批注卡片需要编辑器右侧有约 270px 的空间，窗口过窄时会和正文重叠。
- 置顶主页依赖 Obsidian 文件浏览器的内部方法，未来 Obsidian 更新后可能失效。
- 目前只在 Windows 桌面版上测试过。

## English

An Obsidian plugin for novel writing: word counts in the file explorer, daily writing statistics, a writing dashboard and homepage, and Word-style margin annotations.

Everything applies only to the **writing folder** you choose. Other notes in your vault are left alone.

### Features

**Word counts**

- Chinese is counted per character, English per word; a run of digits or letters-and-digits counts as one. Punctuation, whitespace and Markdown syntax are not counted.
- The file explorer shows a count after each note, and folders show the total of everything inside them, in a different color.
- Files and folders can be ignored (for example, an outline folder) and are left out of all statistics.

**Daily statistics**

- **Today (net)**: how many words your notes actually grew today. Deleting 100 words and writing 100 new ones nets 0; pasted text counts.
- **Today (typed)**: how many words you typed today. Deletions, pastes and undo are not counted.
- **Writing time**: counted while you keep typing in the writing folder, and paused after 30 seconds of inactivity.
- When you change the ignore list, switch writing folders or move a note into the writing folder, that note starts from its current count instead of being counted as written today.
- Shows the date tracking started and which day you are on.

**Dashboard sidebar and homepage note**

- Sidebar: stat cards, recent writing, a 30-day bar chart, a monthly calendar and a year heatmap.
- Homepage note (placed in the writing folder by default): stat cards, recent writing, a 7-day bar chart, the calendar and the heatmap. Its name can be changed in settings.
- The calendar starts on Monday. Page through months, or select the month label to open a year/month picker and go back to any month since tracking started.
- Hover a bar, calendar day or heatmap cell to see that day's word count.
- Selecting a note under recent writing switches to its tab if it is already open instead of opening a duplicate.
- The homepage is pinned to the top of the writing folder in the file explorer, cannot be dragged, and is moved back if it is moved out of the folder.

**Editing records**

- Change any day's net words, typed words and writing time, or change the start date.
- Import records by pasting CSV (`date,net,typed,minutes`) or JSON, or copy all records as JSON.

**Annotations**

- Select text in a note inside the writing folder, then choose **Add annotation** from the context menu or run the command.
- Annotation cards appear in the editor's right margin, aligned with the annotated text. The text column moves left to make room and only overlaps when the window is too narrow.
- Annotated text is underlined; it is highlighted only when its annotation is selected.
- Card text can be selected and copied without editing; select the pencil button to edit.
- Show or hide all annotations from the view header button, a command or settings.
- Annotations are stored in plugin data and **never insert anything into your text**, so word counts are unaffected. They follow notes when renamed or moved.
- If the annotated text is deleted entirely, the annotation is kept and marked as "text not found".

**Other**

- The status bar shows today's net words; select it to open the dashboard.
- A ribbon button opens the dashboard.
- The interface is available in Chinese and English and follows Obsidian's language by default.

### Commands

Every command can be bound to a hotkey in **Settings → Hotkeys**.

| Command | What it does |
|---|---|
| Open dashboard sidebar | Opens the dashboard in the right sidebar |
| Open homepage | Opens the homepage note, creating it if needed |
| Edit writing records | Opens the records editor |
| Add annotation | Annotates the selected text |
| Show or hide annotations | Toggles annotation display |

### Settings

| Setting | Description |
|---|---|
| Writing folder | Notes in this folder are counted. Created if missing; the homepage moves with it |
| Homepage name | File name and title of the homepage note |
| Ignored files and folders | Excluded from word counts, with path suggestions |
| Show dashboard sidebar | Open the dashboard in the right sidebar on startup |
| Create homepage note | Keep a homepage note in the writing folder |
| Pin homepage | Show the homepage first in the writing folder |
| Show today in status bar | Show today's net words in the status bar |
| Show annotations | Show annotation cards in the margin |
| Language | Follow Obsidian / 简体中文 / English |

### Installation

The plugin is not in the community plugin directory yet. To install it manually:

1. Clone this repository, install dependencies and build:
   ```bash
   npm install
   npm run build
   ```
2. Copy the generated `main.js`, plus `manifest.json` and `styles.css`, to `<your vault>/.obsidian/plugins/ob-novel-dashboard/`.
3. Restart Obsidian and enable **Novel Dashboard** in **Settings → Community plugins**.

Requires Obsidian 1.8.7 or later.

### Data and privacy

- The plugin runs entirely locally and makes no network requests.
- Word counts, daily records and annotations are stored in `.obsidian/plugins/ob-novel-dashboard/data.json`.
- The plugin only creates the homepage note in the writing folder, and the writing folder itself when you switch to one that does not exist. It never modifies your text.

### Known limitations

- Annotations are shown in editing mode (Live Preview or Source mode) only, not in Reading view.
- Annotation cards need about 270px of space to the right of the editor and overlap the text in narrow windows.
- Pinning the homepage relies on internal methods of Obsidian's file explorer and may stop working after future Obsidian updates.
- Only tested on Obsidian desktop for Windows so far.
